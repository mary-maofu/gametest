# gametest
 
Test project for trying out Godot and Git as a team. Not the final game repo.
 
## Versions
 
| What | Version |
|---|---|
| Engine | Godot 4.7.2 (standard build, not .NET) |
| Language | GDScript |
 
Everyone must use exactly the same Godot version (check under Help -> About).
 
## Clone
 
```
git clone https://github.com/mary-maofu/gametest.git
```
 
Then in Godot: Import -> select `project.godot` -> Import & Edit.
 
## Rules
 
- `git pull` before you start, `git push` when something works.
- Only one person edits a given scene (`.tscn`) at a time.
- Move or rename files inside Godot, not in Explorer.
- Never use `git push --force`.
- Images and audio (png, jpg, wav, ogg, mp3) go through Git LFS.
